title: "Density Points of a Fat Cantor Set"
date: 2024-12-01
---

A point <span markdown="0">\(p\)</span> of a Lebesgue measurable set <span markdown="0">\(A \subset \mathbb{R}^n\)</span> is called the Lebesgue density point of <span markdown="0">\(A\)</span> if <span markdown="0">\(\lim_{\epsilon \to 0} \frac{\mu(A \cap B(p,\epsilon))}{\mu(B(p,\epsilon))}=1\)</span> where <span markdown="0">\(B(p, \epsilon)\)</span> denotes the open ball of radius <span markdown="0">\(\epsilon\)</span> about <span markdown="0">\(p\)</span>; in some sense this means that <span markdown="0">\(A\)</span> takes 100% of the space about <span markdown="0">\(p\)</span>. In general, if the limit above exists (regardless of whether it's equal to 1 or not), we call it's value the Lebesgue density of <span markdown="0">\(A\)</span> at <span markdown="0">\(p\)</span>, denoted by <span markdown="0">\(\mathrm{dens}_A(p)\)</span>. Fixing any Lebesgue measurable set <span markdown="0">\(A\)</span>, there's a theorem called Lebesgue density theorem which states that for almost every <span markdown="0">\(x \in \mathbb{R}\)</span> we have either <span markdown="0">\(\mathrm{dens}_A(x)=1\)</span> or <span markdown="0">\(\mathrm{dens}_A(x)=0\)</span>. The theorem looks reasonable if we think of simple shapes in space, for example if <span markdown="0">\(A\)</span> is a closed filled square in <span markdown="0">\(\mathbb{R}^2\)</span>, then the interior points have density <span markdown="0">\(1\)</span> while the points in the complement have density 0, and the points on the boundary have measure density <span markdown="0">\(\frac{1}{2}\)</span>, but the boundary of the square is a measure zero in <span markdown="0">\(\mathbb{R}^2\)</span>. Restricting our attention to <span markdown="0">\(\mathbb{R}\)</span> and thinking about it for the favorite set in real analysis, Cantor set, it'll still make sense, because the Cantor set after all has measure zero itself, so those fractions are zero for all of the radii <span markdown="0">\(\epsilon&gt;0\)</span> and point <span markdown="0">\(x \in \mathbb{R}\)</span>. Now one might wonder to twist the situation more by thinking about the fat Cantor set <span markdown="0">\(C\)</span>; where the set now has some mass in contrast with the Cantor set. Then how do the density and non-density points (i.e. points where that limit is either not equal to 1 or it doesn't exist) of <span markdown="0">\(C\)</span> look like? The fat Cantor set contains some easy to find Lebesgue non-density points: the boundary points of the open intervals that we remove at each step have density <span markdown="0">\(\frac{1}{2}\)</span>, let such points in <span markdown="0">\(C\)</span> be denoted by <span markdown="0">\(\mathrm{Ends}(C)\)</span>.

Question: Is there any point in <span markdown="0">\(C \setminus \mathrm{Ends}(C)\)</span> that is a non-density point of <span markdown="0">\(C\)</span>?

<!--more--> 

The answer is Yes.

Let's use a number system <span markdown="0">\(\{ R,L \}^\omega\)</span> for representing the points of the fat Cantor set, which is similar to the representation <span markdown="0">\(\{ 0,2 \}^\omega\)</span> for points of the normal Cantor set in the ternary system, in the sense that we make a tree out of our fat Cantor set and each digit <span markdown="0">\(L\)</span> or <span markdown="0">\(R\)</span> will correspond to moving left or right in the tree. Then in this way each sequence <span markdown="0">\(\{ l_k \} \in \{ R,L \}^\omega\)</span> represents exactly one point of our Cantor set, because the points in the set described by <span markdown="0">\(\{ l_k \}\)</span> can be obtained by intersecting a sequence of nested closed (hence compact) intervals, which is non empty, and further that the intervals are shrinking, hence denoting exactly a point. So for example, in our system, the number <span markdown="0">\(R R R\dots\)</span>  is the right-most point of <span markdown="0">\(C\)</span>. And it's easy to see that the boundary points of <span markdown="0">\(C\)</span> correspond to eventually-constant sequences of <span markdown="0">\(\{ L,R \}^\omega\)</span>.

We now begin the construction of a desired point <span markdown="0">\(p \in C\setminus \mathrm{Ends}(C)\)</span>. We consider the natural numbers <span markdown="0">\(k\in \{ 2,3,4, \dots \}\)</span>, and <span markdown="0">\(\delta _x (\epsilon)=\frac{\mu((x-\epsilon,x+\epsilon)\cap C)}{2\epsilon}\)</span> and we want to construct a point
<span markdown="0">\(\displaystyle p=\underbrace{RR\dots R}_{a_1}\underbrace{L L\dots L}_{a_2}\underbrace{RR\dots R}_{a_3}\dots\in C \setminus \mathrm{Ends}(C)\)</span>
such that <span markdown="0">\(\delta _p\left( \frac{1}{k_{i}} \right)&lt;51 \%\)</span> for a subsequence <span markdown="0">\(\{ k_{i} \}_{i \in \mathbb{N}}\)</span> of <span markdown="0">\(k\)</span>'s. Start with <span markdown="0">\(k_{1}=k=2\)</span> and at first add <span markdown="0">\(a_1\)</span>-many <span markdown="0">\(R\)</span>'s in the beginning of the name of <span markdown="0">\(p\)</span> so that we can be sure that any point in <span markdown="0">\(C\)</span> whose first <span markdown="0">\(a_1\)</span>-many digits are <span markdown="0">\(R\)</span> (will be using the notation <span markdown="0">\(\underbrace{RR\dots R}_{a_1\text{-many}}\bigstar\)</span> for them), is close enough to the right-most possible point of <span markdown="0">\(C\)</span> (call it <span markdown="0">\(q\)</span>) which ensures <span markdown="0">\(\delta _p\left( \frac{1}{k} \right)&lt;51\%\)</span> (this is possible because the right half of the interval <span markdown="0">\((q- 1 /k, q+ 1 /k)\)</span> contains no points in <span markdown="0">\(C\)</span>, meaning that <span markdown="0">\(\delta _q\left( \frac{1}{k} \right) \leq 50\%\)</span>, so if <span markdown="0">\(p\)</span> is close enough to <span markdown="0">\(q\)</span>, we can have the intended inequality). So any number of the form <span markdown="0">\(\underbrace{RR\dots R}_{a_1\text{-many}}\bigstar\)</span> is working for <span markdown="0">\(k=2\)</span>. Let's increment <span markdown="0">\(k\)</span> to <span markdown="0">\(3\)</span>. Now it's possible that any number of the aforementioned form also works for <span markdown="0">\(k=3\)</span>, meaning that for any such <span markdown="0">\(p\)</span> we have <span markdown="0">\(\delta _p(\frac{1}{3})&lt;51 \%\)</span>; if that happened at any <span markdown="0">\(k\)</span>, increment <span markdown="0">\(k\)</span> another time. If <span markdown="0">\(\delta _p\left( \frac{1}{k} \right)&lt;51\%\)</span> for all of the <span markdown="0">\(k\geq {3}\)</span>, meaning that we can increment <span markdown="0">\(k\)</span> indefinitely, then already any point in <span markdown="0">\(\underbrace{RR\dots R}_{a_1\text{-many}}\bigstar\)</span> that is not a boundary point is an ideal point; so as boundary points correspond to eventually-constant <span markdown="0">\(\{ R,L \}^\omega\)</span>-numbers, we can for example set the rest of the digits of <span markdown="0">\(p\)</span> as alternating between <span markdown="0">\(R\)</span> and <span markdown="0">\(L\)</span> every other time. So now assume that we can't increment <span markdown="0">\(k\)</span> indefinitely and there is some <span markdown="0">\(k_{2}^\mathrm{temp} \in \mathbb{N}\)</span> such that not for all <span markdown="0">\(p \in \underbrace{RR\dots R}_{a_1\text{-many}}\bigstar\)</span> we have <span markdown="0">\(\delta _p\left( \frac{1}{k_{2}^\mathrm{temp}} \right)&lt;51\%\)</span>. Surely we can remedy that by adding more <span markdown="0">\(R\)</span>'s at the beginning of our current general form for <span markdown="0">\(p\)</span>, but if we keep doing that with all <span markdown="0">\(k\)</span>'s, then the point <span markdown="0">\(p\)</span> we are constructing would become the right-most boundary point, which we have wanted to avoid. So whenever <span markdown="0">\(\delta _p\left( \frac{1}{k} \right)\)</span> is not always <span markdown="0">\(&lt;51\%\)</span>, it's a good time to make an alteration in our general form. Now if we let <span markdown="0">\(q\)</span> to be the left-most point of <span markdown="0">\(\underbrace{RR\dots R}_{a_1\text{-many}}\bigstar\)</span>, (which is just the left boundary point of the right-most interval at the <span markdown="0">\(a_1\)</span>-level of the construction of the fat Cantor set where <span markdown="0">\(2^{a_1}\)</span> intervals are present), we check whether <span markdown="0">\((q-1 /k_{2}^\mathrm{temp}, q)\cap C\)</span> is empty or not; if it's non empty then increment <span markdown="0">\(k_{2}^\mathrm{temp}\)</span> again and evaluate <span markdown="0">\((q-1 /k_{2}^\mathrm{temp}, q)\cap C\)</span> again; this incrementation eventually stops at some <span markdown="0">\(k\)</span>, calling it <span markdown="0">\(k_{2}\)</span>, because <span markdown="0">\(q\)</span> is an endpoint. When <span markdown="0">\((q-1 /k_{2}, q)\cap C = \varnothing\)</span>, we proceed to add <span markdown="0">\(a_2\)</span>-many <span markdown="0">\(L\)</span>'s to our general form so that (by a similar argument as above) for any <span markdown="0">\(p \in \underbrace{RR\dots R}_{a_1\text{-many}}\underbrace{L L\dots L}_{a_2\text{-many}}\bigstar\)</span>, we have <span markdown="0">\(p\)</span> close enough to <span markdown="0">\(q\)</span> and hence <span markdown="0">\(\delta _p\left( \frac{1}{k_{2}} \right)&lt;51\%\)</span>. And we proceed in the same manner, adding <span markdown="0">\(a_3\)</span>-many <span markdown="0">\(R\)</span>'s, <span markdown="0">\(a_4\)</span>-many <span markdown="0">\(L\)</span>'s, etc.

So after iterating once through the numbers <span markdown="0">\(\frac{1}{k}\)</span>, we have built a subsequence <span markdown="0">\(\{ \frac{1}{k_{i}} \}\)</span>  and a point <span markdown="0">\(p \in C\setminus\mathrm{Ends}(C)\)</span> such that <span markdown="0">\(\liminf \delta _p\left( \frac{1}{k_{i}} \right) \leq \frac{51}{100}\)</span>, showing that either <span markdown="0">\(\mathrm{dens}_C(p)\)</span> does not exists or it's <span markdown="0">\(\leq 51\%\)</span>.

Let me know if you have any other proofs!
